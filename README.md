The Apex Bank Management System is a secure and scalable banking application developed using ASP.NET Core MVC / .NET Core and SQL Server.
The project is designed to manage core banking operations digitally with an easy-to-use interface for both administrators and customers.

This application helps automate banking activities such as account management,
customer registration, money transfer, transaction history, loan management, and secure authentication.
The system follows a clean architecture approach with proper separation of concerns, 
making it suitable for real-world enterprise-level banking applications.
